# 🛡️ OwO Screen Veil

> 適用於 Windows 的輕量化桌面隱私遮罩工具

**OwO Screen Veil** 可透過自訂全域快捷鍵，快速顯示或隱藏全螢幕黑色遮罩，適合在暫時離開座位或需要立即遮蔽桌面內容時使用。

---

## ✨ 主要功能

- **自訂全域快捷鍵**  
  支援指定按鍵，以及 `Ctrl`、`Alt`、`Shift` 組合鍵。

- **多螢幕同步遮罩**  
  可在多個顯示器上同步顯示黑色全螢幕遮罩。

- **密碼解除保護**  
  可設定解除黑色遮罩時所需的密碼。

- **系統匣執行**  
  支援最小化至 Windows 系統匣。

- **隨 Windows 自動啟動**  
  可由使用者自行決定是否啟用。

- **工作模式**  
  可降低系統或螢幕在使用期間進入休眠的可能性。

- **Windows 鍵補救處理**  
  僅在黑色遮罩顯示期間執行按鍵偵測，並重新維持遮罩置頂。

## 📦 下載與使用

請前往 GitHub Releases 下載最新版本。

1. 下載對應版本的 ZIP 壓縮檔。
2. 將 ZIP 完整解壓縮至本機資料夾。
3. 執行 `OwO Screen Veil.exe`。
4. 依照程式介面設定快捷鍵與所需功能。

> [!IMPORTANT]
> 請先完整解壓縮 ZIP，再從本機資料夾執行程式。

## 🖥️ 系統需求

- Windows 10 或 Windows 11
- Microsoft .NET Framework 4.x

---

## 🔒 安全與隱私

- 完全以本機離線方式執行
- 不會主動連線至外部伺服器
- 不會上傳或傳送使用者資料
- 不使用低階鍵盤 Hook 或低階滑鼠 Hook
- 程式設定儲存在目前使用者的 Windows Registry
- 僅在使用者主動啟用時設定隨 Windows 啟動
- 密碼保護僅用於解除本程式顯示的黑色遮罩

---

## ⚠️ 重要限制

**OwO Screen Veil 是桌面隱私遮罩工具，並非 Windows 系統層級的安全鎖定工具。**

`Ctrl + Alt + Delete`、使用者帳戶控制（UAC）、Windows 安全畫面及其他系統層級功能，仍由 Windows 優先處理。

如需系統層級的安全鎖定，請使用 Windows 內建鎖定功能，或組織核准的資訊安全機制。
