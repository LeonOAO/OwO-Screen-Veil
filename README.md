# 🛡️ OwO Screen Veil

> **OwO Screen Veil** 可透過自訂全域快捷鍵，一鍵遮蔽當前顯示畫面，同時維持背景作業正常執行，適合在暫時離開座位或需要立即遮蔽螢幕內容時使用。

---

## ✨ 主要功能

- **自訂全域快捷鍵**  
  支援指定按鍵，以及 `Ctrl`、`Alt`、`Shift` 組合鍵。

- **多螢幕同步遮罩**  
  可在多個顯示器上同步顯示黑色全螢幕遮罩。

- **密碼解除保護**  
  可設定解除黑色遮罩時所需的密碼。

- **系統匣執行**  
  支援最小化至 Windows 系統匣。

- **隨 Windows 自動啟動**  
  可由使用者自行決定是否啟用。

- **工作模式**  
  可阻止系統或螢幕在使用期間進入休眠或登出。

- **Windows 按鍵防護**  
  僅在黑色遮罩顯示期間執行必要的按鍵狀態偵測，藉此維持遮罩置頂，降低遮罩被意外繞過的可能性。

---

## 📦 下載與使用

請前往 GitHub Releases 下載最新版本。

1. 下載對應版本的 ZIP 壓縮檔。
2. 將 ZIP 完整解壓縮至本機資料夾。
3. 執行 `OwO Screen Veil.exe`。
4. 依照程式介面設定快捷鍵與所需功能。

> [!IMPORTANT]
> 請先完整解壓縮 ZIP，再從本機資料夾執行程式。
